# **Radix Sort Algorithm**
- ### _Find the max element in the array._
- ### _Iterate over the digits of max element & apply count sort based on place digit of each element_
- ### _It is not an in-place algorithm._
- ### _It is a Stable sort algorithm._

## **Complexity Analysis**

- ### Time Complexity: O(d*n) where d = no. of digits of max element & since k<=10 so its ignored.

- ### Space Complexity: O(n) since k<=10 so its ignored.
  ### _where k = max place digit_ 
- ### _Better algorithm compared to Count Sort since k<=10._
